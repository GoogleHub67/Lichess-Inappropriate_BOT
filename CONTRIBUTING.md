# Contributing to Lichess Adaptive Chess Partner

Thank you for checking out the project! We welcome contributions to help improve this adaptive chess bot.

## How to Contribute

### Reporting Bugs
* Open an issue in the Issues tab.
* Provide your system setup (Windows/Mac/Linux) and engine paths.
* Include the Lichess game URL and your console error logs.

### Feature Requests
* Suggest new features or difficulty mapping rules by opening an enhancement issue.
* Describe your idea clearly.

### Pull Requests
1. Fork the repository and create your branch from main.
2. Fix bugs or add features without breaking the core event loop.
3. Keep hardware performance limits in mind so the bot remains lightweight.
4. Submit your PR with a clear summary of your changes.
